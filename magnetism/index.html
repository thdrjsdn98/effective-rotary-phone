1. 벡터

1. 벡터와 스칼라

스칼라: 크기만 있는 양(질량, 온도, 전위 등) / 벡터: 크기와 방향을 모두 가지는 양(힘, 전계, 자계 등). 전자기학의 거의 모든 물리량(전계 E, 자계 H, 전속밀도 D, 자속밀도 B)이 벡터이기 때문에, 벡터 연산에 익숙해지는 것이 전자기학 이해의 출발점이다.

2. 벡터의 표현

직각좌표계에서 벡터 A는 A = Axi + Ayj + Azk로 표현한다(i,j,k는 x,y,z축 단위벡터). 벡터의 크기(스칼라량)는 |A| = √(Ax²+Ay²+Az²)이며, 방향은 단위벡터 a = A/|A|로 나타낸다.

3. 벡터의 합과 차

벡터의 덧셈·뺄셈은 성분별로 계산한다: A±B = (Ax±Bx)i + (Ay±By)j + (Az±Bz)k. 기하학적으로는 평행사변형법(덧셈) 또는 삼각형법으로 이해할 수 있다.

4. 벡터의 내적(스칼라곱)

A·B = |A||B|cosθ = AxBx+AyBy+AzBz (θ: 두 벡터 사이의 각). 결과는 스칼라이며, 두 벡터가 이루는 각도나 '한 벡터가 다른 벡터 방향으로 얼마나 작용하는지'를 구할 때 사용한다. 전자기학에서는 일(W=F·d), 자속(Φ=B·S) 등을 구할 때 내적이 등장한다.

벡터의 외적(벡터곱)

A×B = |A||B|sinθ · n (n: A,B가 이루는 평면에 수직인 단위벡터, 오른손법칙으로 방향 결정). 성분으로는 A×B = (AyBz-AzBy)i + (AzBx-AxBz)j + (AxBy-AyBx)k. 결과는 벡터이며, 힘 F=IL×B, 토크, 비오-사바르 법칙 등 자기현상 대부분이 외적으로 표현된다.

5. 벡터의 미분 - 델(∇) 연산자와 3형제

∇ = (∂/∂x)i + (∂/∂y)j + (∂/∂z)k — 이 연산자를 스칼라·벡터에 어떻게 적용하느냐에 따라 3가지 연산이 나온다.
① 기울기(gradient): 스칼라장 V에 적용 → ∇V (벡터). 전위 V로부터 전계 E=-∇V를 구할 때 사용.
② 발산(divergence): 벡터장 A에 적용 → ∇·A (스칼라). 한 점에서 벡터가 '얼마나 퍼져나가는지'를 나타내며, 가우스 법칙의 미분형(∇·D=ρ)에 사용.
③ 회전(curl): 벡터장 A에 적용 → ∇×A (벡터). 벡터장이 한 점 주위로 '얼마나 회전하는지'를 나타내며, 패러데이 법칙(∇×E=-∂B/∂t)에 사용.

6. 벡터의 적분 - 선적분·면적분·체적분

선적분 ∫A·dl: 어떤 경로를 따라 벡터를 적분(예: 일 W=∫F·dl, 기전력 e=∮E·dl) / 면적분 ∫A·dS: 어떤 면을 통과하는 벡터의 양(예: 자속 Φ=∫B·dS, 전속 Ψ=∫D·dS) / 체적분 ∫ρdV: 어떤 부피 안의 양을 적분(예: 전하량 Q=∫ρdV). 발산정리(가우스 정리) ∫∇·A dV = ∮A·dS 와 스토크스 정리 ∫(∇×A)·dS = ∮A·dl 는 적분형과 미분형 법칙을 서로 변환해주는 핵심 도구이다.
✏️ 단원 확인문제 (3문제)
점수: 0 / 100점 (정답 0 / 3문제)

Q1. 두 벡터의 내적(스칼라곱) A·B의 결과는 무엇인가?

💡 해설: 내적의 결과는 크기만 있는 스칼라입니다(A·B=|A||B|cosθ).

Q2. 전위 V로부터 전계 E를 구하는 벡터 연산은?

💡 해설: 전계는 전위의 기울기(gradient)에 음(-)의 부호를 붙인 것입니다.

Q3. 벡터장이 한 점에서 얼마나 퍼져나가는지를 나타내는 연산은?

💡 해설: 발산(∇·A)은 벡터장이 한 점에서 퍼져나가는 정도를 나타냅니다.

2. 정전계

1. 용어 정리

전하(Q): 전기현상을 일으키는 근원 [C] / 전계(E): 단위 정전하가 받는 힘 [V/m] / 전위(V): 단위 정전하가 갖는 위치에너지 [V] / 유전율(ε): 매질이 전기장을 얼마나 잘 전달하는지를 나타내는 상수, 진공중 유전율 ε₀ = 8.855×10⁻¹² [F/m].

2. 쿨롱의 법칙 - 유도

두 점전하 Q1, Q2가 거리 r만큼 떨어져 있을 때 작용하는 힘(실험적으로 확립된 법칙): F = Q1Q2 / (4πε₀r²) [N] (진공 중). 여기서 4πε₀는 '구면 전체로 퍼지는 대칭성'을 반영한 비례상수이다(뒤에서 가우스 법칙으로 이 4π의 의미가 명확해진다). 방향은 두 전하를 잇는 직선 방향이며, 같은 부호면 반발, 다른 부호면 흡인.

3. 전계의 세기 - 유도

전계는 '단위 전하(+1C)가 받는 힘'으로 정의된다: E = F/Q. 쿨롱의 법칙 F=QQ'/(4πε₀r²)에서 시험전하 Q'=1을 대입하면 E = Q/(4πε₀r²) [V/m]이 유도된다. 여러 전하가 있으면 각 전하가 만드는 전계를 벡터로 합산한다(중첩의 원리).

4. 전위 - 유도

전위는 '단위 전하를 무한 원점에서 그 점까지 전계에 대항하여 옮기는 데 필요한 일'로 정의된다: V = -∫(∞→r) E·dl. 점전하의 전계 E=Q/(4πε₀r²)를 대입해 적분하면 V = Q/(4πε₀r) [V]가 유도된다. 전계가 '힘의 장'이라면 전위는 '에너지의 장'이며, 둘의 관계는 E = -∇V (전위가 급격히 변하는 방향으로 전계가 강하다).

5. 전기력선의 성질

전기력선은 전계의 방향과 세기를 시각화한 가상의 선이다. ① (+)전하에서 나와 (-)전하로 들어간다 ② 도체 표면에 수직으로 출입한다 ③ 전기력선끼리 교차하지 않는다 ④ 전위가 높은 곳에서 낮은 곳으로 향한다 ⑤ 임의의 점에서 전계의 세기는 그 점에서의 전기력선 밀도에 비례한다.

6. 전속(전속밀도)과 가우스의 법칙 - 유도

전속 Ψ은 매질에 관계없이 전하 Q와 같은 크기(Ψ=Q)로 정의되는 가상의 선속이다. 전속밀도 D = εE [C/m²] (매질의 유전율을 곱해 매질에 무관하게 만든 양). 반지름 r인 구 표면 전체를 지나는 전속을 생각하면, 구 표면적 4πr²에 D를 곱한 값이 전체 전하 Q와 같아야 하므로: D·4πr² = Q → D = Q/(4πr²). 이것이 가우스의 법칙(적분형): ∮D·dS = Q이며, 여기서 쿨롱법칙의 '4π'가 왜 나왔는지 명확해진다(구 대칭 표면적). 미분형으로는 ∇·D = ρ(발산정리 적용).

7. 전하분포에 따른 전계·전위 - 무한 직선전하

선전하밀도 λ[C/m]인 무한 직선 주위, 거리 r인 원통면(반지름 r, 길이 l)에 가우스법칙을 적용: D·2πrl = λl → D = λ/(2πr), 따라서 E = λ/(2πε₀r). 구 대칭(1/r²)과 달리 원통 대칭에서는 E가 r에 반비례(1/r)한다는 점이 중요한 차이다.

전하분포에 따른 전계·전위 - 무한 평면전하

면전하밀도 σ[C/m²]인 무한 평면 양쪽에 가우스법칙(원통형 가우스면)을 적용하면: D·2S = σS → D = σ/2, 따라서 E = σ/(2ε₀). 평면전하가 만드는 전계는 거리에 관계없이 일정하다는 것이 핵심 특징이다(무한 평행판 콘덴서 내부 전계 유도의 기초가 된다).

전하분포에 따른 전계·전위 - 대전 구도체

전하 Q가 균일하게 분포된 반지름 a인 구도체의 경우: 구 외부(r>a)에서는 전하가 중심에 모인 점전하처럼 작용 → E=Q/(4πε₀r²) (점전하와 동일) / 구 내부(r<a)는 도체이면 내부 전계 E=0(정전차폐), 절연체에 균일 분포된 경우라면 내부는 r에 비례해서 커진다.

8. 전기쌍극자 - 유도

크기가 같고 부호가 반대인 전하 +Q, -Q가 아주 가까운 거리 d만큼 떨어져 있는 것을 전기쌍극자라 하며, 쌍극자 모멘트 p = Qd [C·m]로 정의한다. 쌍극자로부터 먼 거리 r, 축과 이루는 각 θ인 점에서의 전위는 각 전하의 전위를 중첩해 근사하면 V = p cosθ/(4πε₀r²)로 유도된다(점전하의 V∝1/r과 달리 쌍극자는 V∝1/r²로 더 빨리 감소하는 것이 특징 — 두 전하가 서로 상쇄되기 때문).

💡 해설: 쌍극자 모멘트 p = Qd 입니다.

3. 도체계와 정전용량

1. 전위계수와 용량계수·유도계수

n개의 도체가 서로 영향을 주고받을 때, 각 도체의 전위는 모든 도체의 전하량과 전위계수(p)의 선형결합으로 표현된다: V1=p11Q1+p12Q2+..., 반대로 전하는 전위와 용량계수·유도계수(q)의 선형결합: Q1=q11V1+q12V2+.... 전위계수·용량계수는 도체의 형상·배치로 결정되는 상수이며, pii>0, qii>0, qij≤0 (i≠j) 등의 성질을 가진다.

2. 정전용량 - 정의와 평행판 콘덴서 유도

정전용량은 C = Q/V [F]로 정의된다(전하를 얼마나 많이 저장할 수 있는지). 평행판 콘덴서(극판 면적 S, 간격 d)를 유도해보면: 극판의 면전하밀도 σ=Q/S일 때 내부 전계 E=σ/ε=Q/(εS) (앞 단원의 무한평면전하 결과 이용), 전위차 V=Ed=Qd/(εS). 따라서 C = Q/V = εS/d [F] — 면적이 클수록, 간격이 좁을수록, 유전율이 클수록 정전용량이 커진다는 것이 자연스럽게 유도된다.

3. 콘덴서의 연결 - 유도

직렬연결: 각 콘덴서에 걸리는 전하 Q는 같고 전압이 나뉨(저항의 병렬과 유사한 형태) → 1/C = 1/C1+1/C2+... / 병렬연결: 각 콘덴서에 걸리는 전압이 같고 전하가 나뉨(저항의 직렬과 유사한 형태) → C = C1+C2+.... 저항의 직렬·병렬 공식과 정확히 반대로 대응된다는 점을 기억하면 헷갈리지 않는다.

4. 도체계의 에너지 - 유도

콘덴서를 충전하는 과정에서 전하를 조금씩(dq) 옮길 때 필요한 일 dW=v dq=q/C dq를 0부터 Q까지 적분하면: W = Q²/(2C) = QV/2 = CV²/2 [J]. 이 에너지는 콘덴서 내부(유전체)에 전계 형태로 저장된다고 볼 수 있으며, 단위 체적당 에너지(에너지 밀도)는 w = εE²/2 = ED/2 [J/m³]로 유도된다.

도체계에 작용하는 힘 - 정전응력

대전된 도체 표면(면전하밀도 σ)이 받는 단위 면적당 힘(정전응력)은 에너지 밀도와 같은 형태로 f = σ²/(2ε) = εE²/2 [N/m²]로 유도되며, 이는 항상 도체를 바깥쪽으로 잡아당기는(흡인하는) 방향으로 작용한다(콘덴서 극판이 서로 끌어당기는 이유).

4. 유전체와 특수현상

1. 유전체의 분극

유전체(절연체)에 전계를 가하면 내부의 (+),(-) 전하가 미세하게 이동해 쌍극자를 형성하는 현상을 분극이라 한다. 분극의 세기 P = ε₀(εr-1)E [C/m²] (εr: 비유전율)로 표현되며, 전속밀도와의 관계는 D = ε₀E + P = εE로 유도된다(전속밀도는 진공 성분과 분극 성분의 합).

2. 유전체의 경계조건 - 유도

서로 다른 유전체 경계면에서: 전속밀도의 수직(법선)성분은 연속 D1cosθ1 = D2cosθ2 (경계면에 자유전하가 없으면 가우스법칙에서 유도) / 전계의 수평(접선)성분은 연속 E1sinθ1 = E2sinθ2 (전위가 연속이어야 하므로, ∮E·dl=0에서 유도). 두 식을 나누면 굴절의 법칙: tanθ1/tanθ2 = ε1/ε2가 유도된다 — 유전율이 큰 쪽으로 전기력선이 더 많이 꺾여 들어간다.

3. 유전체 사이에 작용하는 힘 - 맥스웰 응력

서로 다른 유전체 경계면에는 맥스웰 응력(정전응력)이 작용하며, 유전율이 작은 쪽에서 큰 쪽으로 잡아당기는 힘이 작용한다. 단위면적당 힘은 앞서 유도한 f=εE²/2와 같은 형태로 표현되며, 경계면에서는 D가 연속이므로 f = D²(1/ε1 - 1/ε2)/2 형태로 정리된다(유전율이 작은 매질 쪽 에너지 밀도가 더 크기 때문에 그쪽이 당겨짐).

4. 복합유전체 콘덴서 - 유도

평행판 콘덴서에 유전체를 극판과 평행하게(직렬) 채우면 각 층의 콘덴서가 직렬 연결된 것과 같고, 극판에 수직하게(병렬) 채우면 병렬 연결된 것과 같다. 즉 3단원의 콘덴서 직렬·병렬 공식을 그대로 적용해 복합유전체의 합성 정전용량을 구할 수 있다.

5. 전기영상법 - 유도

접지된 무한 평면 도체로부터 거리 d만큼 떨어진 점전하 +Q가 있을 때, 도체 표면에는 유도전하가 생겨 복잡한 전계 분포를 만든다. 이때 도체를 없애고 대신 평면 반대편 대칭 위치(거리 d)에 가상의 전하 -Q를 놓으면 원래 도체가 있던 영역에서 동일한 전계·전위 분포를 얻을 수 있다(경계조건이 같기 때문). 이 가상전하를 영상전하라 하며, 점전하가 평면에 끌리는 힘은 두 전하 사이 쿨롱력과 같은 형태로 F = Q²/(4πε₀(2d)²)로 유도된다(거리가 2d임에 주의).

6. 정전계의 특수현상

정전차폐: 도체로 둘러싸인 공간 내부는 외부 전계의 영향을 받지 않는다(패러데이 케이지 원리) / 접지구 도체에 대전체 접근 시: 영상전하법으로 유도전하와 힘을 구할 수 있다 / 대전열: 서로 다른 물질을 마찰시켰을 때 어느 쪽이 (+)/(-)로 대전되는지의 순서.

5. 전기회로

1. 전류 - 미시적 관점

전류는 전하의 흐름 I = dQ/dt [A]이며, 전류밀도는 J = I/A [A/m²]. 도체 내부의 자유전자가 평균 속도 v(드리프트 속도)로 이동한다고 보면 J = nqv (n: 전하 밀도, q: 전하량)로 미시적으로 표현할 수 있다.

옴의 법칙 - 미분형 유도

전류밀도는 전계에 비례한다는 실험적 사실로부터 J = σE (σ: 도전율)가 성립하며, 이것이 옴의 법칙의 미분형(점 옴의 법칙)이다. 이를 도체(길이 l, 단면적 A) 전체에 적분하면 익숙한 V = IR 형태가 유도된다.

2. 저항 - 유도

J=σE, E=V/l, I=JA를 결합하면 I = σ(V/l)A → V = I·(l/(σA)). 따라서 R = l/(σA) = ρl/A [Ω] (ρ=1/σ: 고유저항)이 유도된다 — 길이에 비례, 단면적에 반비례, 도전율에 반비례.

3. 저항과 정전용량의 관계 - 유도

같은 형상의 두 도체 사이를 (a)도전율 σ인 매질로 채우면 저항 R, (b)유전율 ε인 매질로 채우면 정전용량 C가 생긴다고 하자. R=l/(σA), C=εA/l 이므로 곱하면 RC = ε/σ로, 형상(l, A)이 소거되고 매질의 물성치(ε, σ)만으로 정해지는 특수한 관계가 유도된다. 이는 절연물의 누설저항을 구할 때 유용하게 쓰인다.

4. 전력과 열전현상

전력 P=VI=I²R=V²/R [W] (회로이론과 동일). 열전현상 3가지: 제벡 효과(서로 다른 두 금속의 접합부에 온도차를 주면 기전력 발생 — 열전대 원리), 펠티에 효과(두 금속 접합부에 전류를 흘리면 한쪽은 흡열, 다른 쪽은 발열 — 열전냉각 원리), 톰슨 효과(균질한 도체에 전류와 온도구배가 동시에 있으면 열의 흡수·발생이 일어나는 현상). 제벡·펠티에는 서로 가역적인 역과정 관계에 있다.
✏️ 단원 확인문제 (3문제)
점수: 0 / 100점 (정답 0 / 3문제)

Q1. 저항 R = ρl/( )에서 괄호 안은? (알파벳 1글자) (단답형)

💡 해설: R = ρl/A 입니다(A: 단면적).

Q2. 두 금속 접합부에 전류를 흘렸을 때 한쪽은 흡열, 다른 쪽은 발열이 일어나는 현상은?

💡 해설: 펠티에 효과는 전류에 의해 접합부에서 흡열·발열이 일어나는 현상입니다.

6. 정자계

1. 자기현상

자석은 항상 N극과 S극이 쌍으로 존재하며(자하는 단독으로 존재할 수 없음, 단극자 없음), 같은 극끼리는 반발, 다른 극끼리는 흡인한다. 이 현상은 전기현상과 형태적으로 매우 유사해서, 전계·전위 관련 공식들과 1:1로 대응시켜 이해하면 암기 부담이 크게 줄어든다.

2. 자하(자극)에 의한 자계 - 쿨롱의 법칙(자기)

두 자극 m1, m2 사이의 힘: F = m1m2/(4πμ₀r²) [N] (μ₀: 진공의 투자율 = 4π×10⁻⁷ [H/m]) — 전기의 쿨롱법칙과 완전히 같은 형태(ε₀ 대신 μ₀). 자계의 세기는 단위 자극(+1Wb)이 받는 힘으로 정의: H = m/(4πμ₀r²) [AT/m].

전기-자기 대응관계 표

전기의 Q(전하)↔자기의 m(자극), ε(유전율)↔μ(투자율), E(전계)↔H(자계), V(전위)↔U(자위), D(전속밀도)↔B(자속밀도) — 이 대응관계만 알면 정전계에서 배운 모든 유도과정(가우스법�식, 경계조건, 에너지 등)을 자기 쪽에도 그대로 적용할 수 있다.

3. 전류에 의한 자계 - 비오-사바르 법칙 유도

전류 I가 흐르는 미소 길이 dl이 거리 r만큼 떨어진 점에 만드는 자계는 실험적으로 dH = I·dl×a_r / (4πr²) [AT/m] (a_r: r방향 단위벡터)로 주어진다(비오-사바르 법칙). 이를 전체 도선에 대해 적분하면 다양한 형태의 전류가 만드는 자계를 구할 수 있다.

무한직선전류의 자계 - 유도

비오-사바르 법칙을 무한직선에 대해 적분하면 H = I/(2πr) [AT/m]가 유도된다(원통 대칭 → 앞서 배운 무한직선전하의 전계 E=λ/2πε₀r와 완전히 같은 1/r 형태로 대응됨). 방향은 오른나사 법칙(앙페르의 오른나사 법칙)으로 결정.

원형코일 중심의 자계 - 유도

반지름 a인 원형 코일에 전류 I가 흐를 때, 코일 중심(축 위)의 자계는 비오-사바르 법칙 적분 결과 H = I/(2a) [AT/m]로 유도된다. N번 감으면 H=NI/(2a).

앙페르의 주회적분 법칙

비오-사바르 법칙을 폐경로에 대해 적분하면 ∮H·dl = I (폐경로를 관통하는 전류의 합)라는 훨씬 간단한 형태로 정리된다(가우스 법칙의 자기 버전). 대칭성이 좋은 경우(무한직선, 솔레노이드 등)에는 비오-사바르 적분보다 앙페르 법칙을 쓰는 것이 훨씬 빠르다.

4. 전자력과 특수현상 - 로렌츠 힘과 플레밍 법칙

자계 내에서 운동하는 전하가 받는 힘: F = qv×B [N] (로렌츠 힘). 전류가 흐르는 도체(길이 l)가 자계 내에서 받는 힘은 F = BIl sinθ [N]로 유도되며(전하의 흐름 전체에 대한 로렌츠 힘의 합), 방향은 플레밍의 왼손법칙(엄지-힘, 검지-자계, 중지-전류)으로 결정한다.

홀 효과

전류가 흐르는 도체(또는 반도체)에 수직으로 자계를 가하면, 로렌츠 힘에 의해 전하가 한쪽으로 쏠려 도체 양 옆면 사이에 전위차가 발생하는 현상을 홀 효과라 한다. 반도체의 캐리어 종류(전자/정공) 판별이나 자계 측정 센서에 활용된다.

7. 자성체와 자기회로

1. 자성체의 종류

자성체 분류

강자성체(비투자율 μr≫1, 철·니켈·코발트 등 — 외부 자계를 강하게 강화) / 상자성체(μr이 1보다 약간 큼, 알루미늄·백금 등 — 약하게 자화) / 반자성체(μr이 1보다 약간 작음, 구리·은·물 등 — 외부 자계와 반대로 약하게 자화). 이는 전기의 유전체 분극과 유사한 원리로, 물질 내부 자기 쌍극자(전자의 스핀·궤도운동)의 정렬 정도로 설명된다.

2. 자화의 세기 - 유도

자성체가 자화된 정도를 나타내는 자화의 세기 J = χH [Wb/m²] (χ: 자화율). 자속밀도와의 관계는 전기의 D=ε₀E+P와 완전히 대응되는 형태로 B = μ₀H + J = μ₀(1+χ/μ₀)H = μH가 유도된다(μ=μ₀μr: 절대투자율).

3. 자성체의 경계조건 - 유도

정전계 경계조건과 동일한 방식으로 유도된다: 자속밀도의 수직(법선) 성분은 연속 B1cosθ1=B2cosθ2 (자속연속의 원리 ∇·B=0에서 유도) / 자계의 수평(접선) 성분은 연속 H1sinθ1=H2sinθ2 (전류가 없으면 ∮H·dl=0에서 유도). 두 식을 나누면 tanθ1/tanθ2 = μ1/μ2 — 유전체의 굴절법칙과 완전히 같은 형태(ε↔μ만 바뀜).

4. 자기회로 - 자기옴의 법칙 유도

철심에 코일을 N번 감고 전류 I를 흘리면 기자력 F = NI [AT]가 발생한다. 이는 전기회로의 기전력에 대응된다. 자속 Φ는 전류 I에 대응되고, 자기저항 Rm = l/(μS) [AT/Wb]는 전기저항 R=l/(σA)와 완전히 같은 형태로 유도된다(σ↔μ 대응). 따라서 Φ = F/Rm = NI/Rm — 이것이 '자기옴의 법칙'이며, 전기회로의 V=IR과 1:1 대응된다.

자기회로의 직렬·병렬 연결

전기저항의 직렬·병렬 공식이 그대로 자기저항에도 적용된다: 자기회로가 직렬이면 Rm(전체)=Rm1+Rm2+..., 병렬이면 1/Rm(전체)=1/Rm1+1/Rm2+.... 공극(air gap)이 있는 자기회로는 철심 부분과 공극 부분의 자기저항을 직렬로 더해 계산한다(공극의 투자율은 μ₀이므로 자기저항이 매우 커서, 작은 공극도 전체 자기저항에 큰 영향을 준다).

8. 전자유도와 인덕턴스

1. 전자유도 법칙 - 패러데이의 법칙 유도

코일을 지나는 자속 Φ가 시간에 따라 변하면 코일에 기전력이 유도된다는 것이 패러데이의 전자유도 법칙이다: e = -N(dΦ/dt) [V] (N: 코일 감은 수). 음(-)부호는 렌츠의 법칙(유도기전력은 자속의 변화를 방해하는 방향으로 발생)을 반영한 것이다 — 에너지 보존 법칙의 필연적 결과로 이해할 수 있다.

2. 도체 운동에 의한 유도기전력 - 유도

자계 B 속에서 도체(길이 l)가 속도 v로 움직일 때, 도체 내 자유전자가 받는 로렌츠 힘(F=qv×B)이 전하를 이동시켜 기전력을 만든다. 단위전하당 힘을 도체 길이에 대해 적분하면 e = Blv sinθ [V] (θ: B와 v가 이루는 각)가 유도된다 — 이것이 플레밍의 오른손 법칙(발전기 원리)의 정량적 표현이다.

3. 와전류와 표피전류

와전류(맴돌이전류): 시간에 따라 변하는 자속이 도체 내부를 지날 때, 도체 내부에 소용돌이 형태로 유도되는 전류. 이로 인한 줄열 손실(와전류손)을 줄이기 위해 변압기 철심을 얇은 규소강판을 겹쳐(적층) 만든다. 표피효과: 고주파 전류일수록 도체 표면 쪽으로 전류가 집중되는 현상. 표피두께 δ = √(2/(ωμσ))로 유도되며, 주파수가 높을수록·투자율과 도전율이 클수록 표피두께는 얇아진다(전류가 표면에 더 집중됨).

4. 인덕턴스 - 정의

자기인덕턴스 L = NΦ/I [H] (코일 자신의 전류 변화가 스스로에 만드는 유도기전력의 비례상수). 패러데이 법칙과 결합하면 e = -L(dI/dt)가 유도된다(전류가 급히 변할수록 큰 역기전력이 발생 — 코일이 전류 변화를 방해하는 이유). 상호인덕턴스 M은 한 코일의 전류 변화가 다른 코일에 만드는 유도기전력의 비례상수: e2 = -M(dI1/dt).

5. 인덕턴스의 계산 - 솔레노이드 유도

길이 l, 단면적 S, 감은 수 N인 솔레노이드(공심)에 전류 I를 흘리면 내부 자계 H=NI/l (앙페르 법칙), 자속 Φ=BS=μHS=μNIS/l. 인덕턴스 정의 L=NΦ/I에 대입하면 L = μN²S/l [H]가 유도된다 — 감은 수의 제곱(N²)에 비례한다는 점이 핵심(전기저항 R∝l과 달리, 인덕턴스는 N을 두 배로 감으면 4배가 된다).

인덕턴스의 계산 - 동축케이블·평행도선

동축케이블(내도체 반지름 a, 외도체 반지름 b)의 단위길이당 인덕턴스는 L = (μ/2π)ln(b/a) [H/m]로 유도되며(원통 대칭 자계를 자속 적분), 평행 왕복도선(간격 d, 도체반지름 a)의 경우도 로그함수 형태로 유도된다. 두 경우 모두 기하학적 비율의 로그함수로 표현된다는 공통점이 있다.

9. 전자계

1. 유전체 손실각

교류 전계 하의 실제 유전체는 이상적이지 않아 에너지 손실이 발생하며, 이를 복소 유전율 ε = ε' - jε''로 표현한다(ε': 저장 성분, ε'': 손실 성분). 유전체 손실각 δ는 tanδ = ε''/ε'로 정의되며, tanδ가 클수록 유전체에서 열로 소모되는 에너지 비율이 크다(절연물의 품질을 나타내는 중요한 지표).

2. 맥스웰의 전자방정식 - 4개 방정식 정리

전자기학 전체를 4개의 방정식으로 통합한 것이 맥스웰 방정식이다. 지금까지 배운 법칙들이 어떻게 여기에 다 들어있는지 확인해보자.
① 패러데이의 법칙(유도): ∇×E = -∂B/∂t — 시간에 따라 변하는 자속밀도가 전계의 회전(소용돌이)을 만든다(8단원 전자유도 법칙의 미분형).
② 앙페르-맥스웰 법칙: ∇×H = J + ∂D/∂t — 전류(J)뿐 아니라 시간에 따라 변하는 전속밀도(변위전류, ∂D/∂t)도 자계의 회전을 만든다는 것이 맥스웰의 핵심 통찰(6단원 앙페르 법칙의 확장형 — 원래 앙페르 법칙은 J항만 있었는데, 맥스웰이 변위전류 항을 추가해서 전자파의 존재를 예측할 수 있게 됨).
③ 가우스 법칙(전기): ∇·D = ρ — 전하가 있는 곳에서 전속밀도가 발산한다(2단원 가우스 법칙의 미분형).
④ 가우스 법칙(자기): ∇·B = 0 — 자속은 발산하지 않는다(자기 단극자가 존재하지 않는다는 의미, 6단원에서 배운 'N극·S극은 항상 쌍으로 존재'의 수학적 표현).

3. 전자계의 해석 - 전자파의 유도

맥스웰 방정식 ①과 ②를 결합하면(진공, 전하·전류가 없는 공간을 가정) 전계와 자계가 서로를 유도하며 공간을 퍼져나가는 파동방정식이 유도된다: ∇²E = με(∂²E/∂t²). 이 파동방정식의 해가 바로 전자파이며, 진행속도는 v = 1/√(εμ)로 유도된다. 진공 중에서는 v=1/√(ε₀μ₀) ≈ 3×10⁸ [m/s] — 바로 빛의 속도와 일치한다(맥스웰이 이 결과로부터 '빛도 전자파의 일종'임을 예측한 것이 전자기학 역사상 가장 극적인 순간 중 하나).

전자계 요약 - 대응관계로 정리하기

지금까지의 모든 유도과정을 관통하는 것은 전기와 자기의 완벽한 대칭성이다. Q↔m, ε↔μ, E↔H, V↔U, D↔B, 정전용량 C↔인덕턴스 L(형태는 다르지만 '저장'이라는 역할이 대응), 전류에 의한 자계(6단원)와 전자유도(8단원)가 맥스웰 방정식 ①·②로 통합되고, 결국 전계와 자계는 하나의 '전자계'라는 실체의 두 측면임을 맥스웰 방정식이 보여준다.

Q2. 맥스웰이 앙페르 법칙에 새롭게 추가한 항은?
