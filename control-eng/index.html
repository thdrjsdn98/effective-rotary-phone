2. 블록선도와 신호흐름선도

1. 블록선도 - 기본 결합

직렬: G1×G2 / 병렬: G1+G2 / 피드백: C/R = G/(1±GH)(부궤환이면 분모 1+GH). 이 세 가지 결합만 알면 아무리 복잡한 블록선도도 등가변환을 반복해 하나의 전달함수로 정리할 수 있다.

공식 유도 - 피드백 결합

블록도에서 C=G·E, E=R∓C·H(부궤환이면 -). 두 식을 연립하면 C=G(R-CH) → C+GCH=GR → C(1+GH)=GR. 따라서 C/R = G/(1+GH)가 유도된다.

2. 신호흐름선도와 메이슨의 이득공식

신호흐름선도는 블록선도를 점(마디)과 화살표(가지)로 더 간단히 표현한 것이다. 전체 전달함수는 메이슨의 이득공식으로 한 번에 구한다: M = Σ(Pk·Δk) / Δ (Pk: k번째 전방경로 이득, Δ=1-ΣL1+ΣL2-ΣL3+... : 신호흐름선도 행렬식, L1은 개별 루프이득의 합, L2는 서로 접촉하지 않는 두 루프 이득의 곱의 합, Δk는 Pk와 접촉하는 부분을 제거한 Δ).

간이 전달함수법(메이슨 공식 적용 절차)

① 전방경로(입력에서 출력까지 한 방향으로 가는 경로)를 모두 찾아 이득 Pk를 구한다 ② 폐루프(같은 마디로 되돌아오는 경로)를 모두 찾아 각 루프이득 L을 구한다 ③ Δ=1-(모든 루프이득의 합)+(서로 만나지 않는 두 루프이득의 곱의 합)-... 로 계산한다 ④ Pk·Δk를 모두 더해 Δ로 나누면 전체 전달함수가 나온다. 블록선도를 하나하나 등가변환하는 것보다 빠르다는 것이 장점이다.
✏️ 단원 확인문제 (3문제)
점수: 0 / 100점 (정답 0 / 3문제)

💡 해설: 직렬 결합의 합성 전달함수는 두 전달함수의 곱입니다.

3. 시간영역 해석

2. 1차 제어계의 시간응답 특성

1차 지연요소 G(s)=1/(1+Ts)에 스텝입력(1/s)을 가하면 C(s)=1/[s(1+Ts)]. 부분분수분해 후 역라플라스하면 c(t) = 1-e^(-t/T)가 유도된다. T(시정수)가 지나면 최종값의 약 63.2%, 3T에서 약 95%, 5T에서 사실상 100%(정상상태)에 도달한다.

3. 특성근의 위치에 따른 과도응답

특성방정식의 근(특성근)이 s평면의 어디에 있는지로 응답 형태가 결정된다.
특성근의 위치응답 형태
좌반면의 실근지수적으로 감쇠(비진동), 안정
좌반면의 복소근진동하며 감쇠, 안정
허수축 위일정한 진폭으로 계속 진동(임계안정)
우반면진폭이 점점 커짐, 불안정
실수부의 부호가 안정성을, 허수부의 유무가 진동 여부를 결정한다는 것이 핵심 원리다.

4. 지연제어계(2차계)의 과도응답 - 표준형

2차 제어계의 표준형: G(s) = ωn² / (s² + 2ζωn·s + ωn²) (ωn: 고유각주파수, ζ: 감쇠비). 특성방정식의 근을 근의 공식으로 풀면 s=-ζωn±jωn√(1-ζ²)가 나오며, 이 판별식(1-ζ²)의 부호로 감쇠 형태가 정해진다.

2차계 감쇠비에 따른 분류

조건명칭응답 형태
ζ > 1과제동진동 없이 서서히 정상값 도달
ζ = 1임계제동진동 없이 가장 빠르게 도달
0 < ζ < 1부족제동진동하며 감쇠
ζ = 0무제동감쇠 없이 계속 진동
오버슈트·정정시간 공식: 최대오버슈트 Mp = e^(-πζ/√(1-ζ²)) (감쇠비가 작을수록 오버슈트가 커짐), 정정시간(2% 기준) Ts ≈ 4/(ζωn).

4. 주파수영역 해석

1. 주파수 전달함수

전달함수 G(s)에서 s를 jω로 치환한 G(jω)를 주파수 전달함수라 한다. 정현파 입력을 가했을 때 정상상태 출력의 크기·위상이 어떻게 변하는지를 나타내며, |G(jω)|는 이득, ∠G(jω)는 위상각이다.

2. 벡터궤적

주파수 ω를 0→∞로 변화시킬 때 G(jω)가 복소평면에 그리는 자취를 벡터궤적이라 한다. 1차 지연요소 G(jω)=K/(1+jωT)의 벡터궤적은 반원을 그리는데(실수축 위 K에서 시작해 원점으로 수렴), 이는 회로이론의 R-L 임피던스 벡터궤적과 같은 원리(1차 함수 형태의 궤적은 반원이 된다)다.

3. 보드선도

1차 지연요소의 보드선도(이득선도) 개형 — 차단주파수 이후 -20dB/decade로 감소
보드선도는 이득(20log|G(jω)| [dB])과 위상을 가로축(로그 주파수)에 대해 각각 그린 그래프이다. 1차 지연요소는 차단주파수(1/T) 이전에는 이득이 거의 0dB로 평평하다가, 이후로는 -20dB/decade(주파수가 10배 될 때마다 이득이 20dB씩 감소) 기울기로 떨어진다 — 이 '-20dB/decade' 값은 1차 요소 하나당 정해지는 고정된 기울기로, 2차 요소는 -40dB/decade가 된다.

5. 제어계의 안정도

1. 안정도의 개요

제어계가 안정하려면 특성방정식의 모든 근(특성근)이 s평면의 좌반면에 있어야 한다(3단원에서 배운 특성근 위치와 응답의 관계가 안정도 판별의 근거가 된다). 안정도를 판별하는 방법에는 대수적 방법(루스), 기하학적 방법(나이퀴스트), 주파수응답 기반 방법(보드선도)이 있다.

2. 루스 안정도 판별법

특성방정식의 계수만으로(근을 직접 구하지 않고도) 안정도를 판별하는 대수적 방법. 계수들을 표 형태(루스 배열)로 나열해 계산하며, 제1열의 부호변화가 없으면 안정, 부호변화의 개수 = 우반면에 있는 불안정근의 개수다. 계산이 복잡한 근을 직접 구하지 않아도 된다는 것이 최대 장점이다.

3. 나이퀴스트 안정도 판별법

개루프 주파수응답 G(jω)H(jω)의 나이퀴스트 선도
개루프 전달함수의 주파수응답(나이퀴스트 선도)이 복소평면의 (-1, j0)점을 감싸는 횟수로 폐루프 시스템의 안정도를 판별한다. 루스 판별법과 달리 개루프 주파수응답만 알면 판별할 수 있어서, 실험적으로 측정한 데이터로도 안정도를 확인할 수 있다는 장점이 있다.

4. 보드선도에 의한 안정도 판별법

보드선도에서 이득여유(GM): 위상이 -180°가 되는 주파수에서의 이득 여유량 / 위상여유(PM): 이득이 0dB가 되는 주파수에서의 위상 여유량. 안정한 계는 이득여유·위상여유가 모두 양수(+)여야 하며, 여유가 클수록 안정도에 더 여유가 있다는 뜻이다(실무에서는 GM 6dB 이상, PM 30~60° 정도를 안정성 확보 기준으로 흔히 사용한다).
✏️ 단원 확인문제 (3문제)
점수: 0 / 100점 (정답 0 / 3문제)

💡 해설: 모든 특성근이 좌반면에 있어야 안정합니다.

💡 해설: 나이퀴스트 판별법은 (-1,j0)점을 감싸는 횟수로 안정성을 판별합니다.

6. 근궤적

1. 근궤적의 개요

개루프 이득 K를 0→∞로 변화시킬 때 폐루프 특성근이 그리는 궤적(근궤적)
개루프 이득 K를 0에서 무한대로 변화시킬 때, 폐루프 특성방정식의 근(특성근)이 s평면에서 그리는 궤적을 근궤적이라 한다. K=0일 때는 개루프 극에서 출발하고, K=∞일 때는 개루프 영점(또는 무한원점)에서 끝난다.

2. 근궤적 작성법 - 주요 규칙

규칙내용
가지 수극의 개수(=차수)만큼 근궤적 가지가 존재
실수축 위 존재조건그 점 오른쪽의 극·영점 개수의 합이 홀수인 구간
점근선의 개수극의 개수 - 영점의 개수
점근선의 교차점(중심)(Σ극 - Σ영점) / (극의 개수 - 영점의 개수)
허수축과의 교차점루스 판별법으로 임계안정 조건(K값)을 구해서 확인
이 규칙들을 조합하면 특성방정식을 직접 풀지 않고도 근궤적의 대략적인 모양을 빠르게 스케치할 수 있다 — 근궤적이 허수축을 넘어가는 순간이 바로 시스템이 불안정해지는 임계 K값이라는 점에서 근궤적법과 안정도 판별법(5단원)이 서로 연결된다.
✏️ 단원 확인문제 (2문제)
점수: 0 / 100점 (정답 0 / 2문제)

Q1. 근궤적은 개루프 이득 K를 어떻게 변화시킬 때 그리는 궤적인가?

💡 해설: 근궤적은 K를 0부터 무한대까지 변화시킬 때 그리는 궤적입니다.

Q2. 근궤적의 점근선 개수는 (극의 개수) - ( )로 구한다. 괄호 안은? (단답형)

💡 해설: 점근선의 개수는 극의 개수에서 영점의 개수를 뺀 값입니다.

7. 상태공간법

1. 상태방정식

상태공간 표현의 블록도 — 적분기(∫)를 중심으로 상태 x(t)가 갱신된다
고차 미분방정식을 여러 개의 1차 연립 미분방정식(행렬 형태)으로 표현한 것: x'(t) = Ax(t) + Bu(t) (상태방정식), y(t) = Cx(t) + Du(t) (출력방정식). x는 상태변수(시스템의 미래 거동을 결정하는 최소 개수의 변수), A는 시스템 행렬, B는 입력행렬, C는 출력행렬, D는 직접전달행렬이다.

2. 상태천이행렬

상태방정식의 해는 x(t) = Φ(t)x(0) + ∫Φ(t-τ)Bu(τ)dτ 형태로 주어지며, 여기서 Φ(t) = e^(At) = L⁻¹[(sI-A)⁻¹]를 상태천이행렬이라 한다. 초기상태 x(0)이 시간에 따라 어떻게 '전이'되는지를 나타내는 행렬로, 스칼라 미분방정식의 해에 나오는 e^(-at)를 행렬로 확장한 개념이다.

3. z변환

디지털(이산시간) 제어계를 다루기 위한 변환으로, 라플라스 변환의 이산시간 버전이다. z = e^(sT) (T: 샘플링 주기)의 관계로 s평면과 z평면이 대응된다. 연속시스템의 s평면 좌반면(안정영역)은 z평면에서 단위원 내부에 대응되며, 이것이 이산시스템의 안정 조건이다.
✏️ 단원 확인문제 (3문제)
점수: 0 / 100점 (정답 0 / 3문제)

Q1. 상태방정식의 일반형 x'(t) = Ax(t) + ___에서 빈칸은? (단답형)

💡 해설: 상태방정식은 x'(t) = Ax(t) + Bu(t)입니다.

Q2. 상태천이행렬 Φ(t)를 라플라스 역변환으로 나타내면?

💡 해설: Φ(t) = e^(At) = L⁻¹[(sI-A)⁻¹] 입니다.

Q3. z변환에서 s평면의 좌반면(안정영역)은 z평면의 어디에 대응되는가?

💡 해설: s평면 좌반면은 z평면의 단위원 내부에 대응됩니다.

8. 시퀀스제어

1. 시퀀스제어 개요

미리 정해진 순서에 따라 각 단계를 순차적으로 진행하는 제어 방식. 유접점(릴레이·전자접촉기의 물리적 접점 사용)과 무접점(반도체 소자 사용) 방식으로 구분되며, a접점(메이크접점, 평소 열림→동작시 닫힘)과 b접점(브레이크접점, 평소 닫힘→동작시 열림)이 기본 단위다.

법칙식
교환법칙A+B=B+A, A·B=B·A
흡수법칙A+AB=A, A(A+B)=A
드모르간의 법칙(A+B)'=A'·B', (A·B)'=A'+B'
보수법칙A+A'=1, A·A'=0
드모르간의 법칙은 복잡한 논리식을 AND/OR/NOT만으로 단순화하거나, NAND/NOR만으로 회로를 재구성할 때 가장 자주 쓰이는 핵심 도구다.

Q1. 평소에는 열려 있다가 동작 시 닫히는 접점은?

💡 해설: a접점(메이크접점)은 평소 열려 있다가 동작 시 닫힙니다.

Q2. 두 접점을 직렬로 연결하면 어떤 논리회로가 되는가?

💡 해설: 접점 직렬연결은 AND회로에 해당합니다.

Q3. 드모르간의 법칙에서 (A+B)' = A'·( )이다. 괄호 안은? (단답형)

💡 해설: (A+B)' = A'·B' 입니다.
