1. 전기이론

1. 전기회로

전류가 전원(+극)에서 나와 부하를 거쳐 전원(-극)으로 돌아오는 순환 경로를 전기회로라 한다.

2. 옴의 법칙

V = IR, I = V/R, R = V/I — 전압은 전류·저항에 비례, 전류는 전압에 비례·저항에 반비례

3. 키르히호프의 법칙

KCL(전류법칙): 한 절점에서 유입 전류의 합 = 유출 전류의 합 / KVL(전압법칙): 폐회로에서 기전력의 합 = 전압강하의 합

4. 저항의 접속

직렬: R = R1+R2+... / 병렬: 1/R = 1/R1+1/R2+... → R=R1R2/(R1+R2)(2개일 때)

5. 분압법칙 및 분류법칙

직렬회로 분압: V1 = R1/(R1+R2)×V / 병렬회로 분류: I1 = R2/(R1+R2)×I (자기 저항이 아닌 상대편 저항의 비율)

6. 전지의 직·병렬 연결

기전력 E, 내부저항 r인 전지 n개 — 직렬: 전압 nE, 내부저항 nr / 병렬: 전압 E(불변), 내부저항 r/n

7. 전력, 전력량

전력 P = VI = I²R = V²/R [W] / 전력량 W = Pt [J] / 1kWh = 860kcal

8. 휘스톤 브리지

평형 조건: R1R3 = R2R4 — 평형 시 검류계(G)에 전류가 흐르지 않는다

9. 배율기와 분류기

배율기: 전압계 범위 확대, 내부저항에 직렬로 큰 저항 → Rm=(m-1)Rv / 분류기: 전류계 범위 확대, 내부저항에 병렬로 작은 저항 → Rs=Ra/(n-1)

✏️ 단원 확인문제 (6문제)
점수: 0 / 100점 (정답 0 / 6문제)

Q1. 전류가 전원의 (+)극에서 나와 회로를 거쳐 돌아오는 경로를 무엇이라 하는가?

💡 해설: 전류가 순환하는 경로를 전기회로라 합니다.

Q2. 저항 R=10Ω에 전압 V=100V를 걸었을 때 흐르는 전류 I[A]는? (숫자만) (단답형)

💡 해설: I=V/R=100/10=10A 입니다.

Q3. 직렬회로에서 전체 저항이 R1+R2일 때, R1에 걸리는 전압(분압)은?

💡 해설: 분압법칙: V1 = R1/(R1+R2) × V 입니다.

Q4. 기전력 E, 내부저항 r인 전지 n개를 직렬로 연결했을 때 전체 내부저항은?

💡 해설: 전지를 직렬연결하면 내부저항도 n배가 되어 nr이 됩니다.

Q5. 휘스톤 브리지가 평형일 때 성립하는 조건은?

💡 해설: 휘스톤 브리지 평형조건은 마주보는 저항의 곱이 같은 R1R3=R2R4 입니다.

Q6. 전압계의 측정범위를 확대하기 위해 직렬로 연결하는 것은?

💡 해설: 배율기는 전압계에 직렬로 연결해 측정범위를 넓히는 저항입니다.

2. 정현파 교류

1. 교류

시간에 따라 크기와 방향이 주기적으로 변하는 전류·전압. 대표적으로 정현파(사인파) 교류를 다룬다.

2. 용어

주기 T=1/f [s], 주파수 f [Hz], 각속도 ω=2πf [rad/s]

3. 정현파 교류의 표시

순시값 v(t) = Vm sin(ωt+θ) — Vm: 최댓값, θ: 위상각

4. 파형별 실효값·평균값·파고율·파형률

정현파: 실효값=Vm/√2, 평균값=2Vm/π, 파고율(최댓값/실효값)=√2, 파형률(실효값/평균값)≈1.11

5. 정현파 교류의 다양한 표현법

삼각함수 표시, 페이저(극형식) V∠θ, 복소수(직각좌표) a+jb 표시가 서로 호환된다

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 주파수가 60Hz일 때 주기 T[s]는? (분수 형태로 1/60 입력) (단답형)

💡 해설: T=1/f=1/60초 입니다.

Q2. 주파수 60Hz의 각속도 ω[rad/s]는? (정수로 입력) (단답형)

💡 해설: ω=2πf=2π×60≈377 rad/s 입니다.

Q3. 정현파의 실효값을 최댓값 Vm으로 나타내면?

💡 해설: 정현파의 실효값은 Vm/√2 입니다.

Q4. 정현파의 파고율(최댓값/실효값)은 약 얼마인가?

💡 해설: 파고율은 √2≈1.414 입니다.

Q5. 정현파 교류를 크기와 위상각으로 표시하는 방법을 무엇이라 하는가?

💡 해설: 페이저(극형식)는 V∠θ와 같이 크기와 위상각으로 표시하는 방법입니다.

3. R-L-C 교류회로

1. 수동소자

에너지를 소비·저장만 하는 소자 — 저항 R, 인덕터 L, 커패시터 C

2. 수동소자의 응답

R: 전압·전류 동상, Z=R / L: 전류가 전압보다 90° 뒤짐, Z=jωL / C: 전류가 전압보다 90° 앞섬, Z=1/jωC

3. R-L-C 직렬회로

임피던스 Z = R + j(XL−XC), |Z|=√(R²+(XL−XC)²)

4. R-L-C 병렬회로

어드미턴스 Y = 1/R + j(1/XC − 1/XL) = G + j(BC−BL)

5. 공진회로

직렬공진(XL=XC): 임피던스 최소(=R), 전류 최대 / 병렬공진: 임피던스 최대, 전류 최소 / f0=1/(2π√LC)

✏️ 단원 확인문제 (5문제)
점수: 0 / 100점 (정답 0 / 5문제)

Q1. 인덕터(L)에서 전류는 전압보다 위상이 어떻게 되는가?

💡 해설: 인덕터는 전류가 전압보다 90도 뒤지는(지상) 특성을 가집니다.

Q2. R-L-C 직렬회로의 임피던스 Z를 나타낸 식은?

💡 해설: 직렬회로의 임피던스는 Z=R+j(XL-XC) 입니다.

Q3. R-L-C 병렬회로에서 저항의 역수(R의 컨덕턴스)를 나타내는 기호는? (알파벳 1글자) (단답형)

💡 해설: 어드미턴스 Y=G+jB에서 G는 컨덕턴스(1/R)입니다.

Q4. 직렬 공진 시 회로의 임피던스는 어떻게 되는가?

💡 해설: 직렬공진 시 리액턴스가 상쇄되어 임피던스는 R만 남아 최소가 됩니다.

Q5. 공진주파수 f0 = 1/(2π√( ))에서 괄호 안은? (단답형)

💡 해설: 공진주파수 f0=1/(2π√LC) 입니다.

4. 교류전력

1. 각 회로소자에서의 교류전력

저항 R: 유효전력만 소비(P=I²R) / 인덕터 L, 커패시터 C: 무효전력만 존재, 평균 유효전력은 0

2. 최대전력의 전송

내부저항 R0인 전원에서 부하저항 RL=R0일 때 최대전력이 전달되며, 이때 Pmax = E²/4R0

3. 복소전력과 전력의 측정

복소전력 S = P + jQ = VI* (I*는 전류의 켤레복소수) — 크기 |S|는 피상전력

✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 인덕터(L)와 커패시터(C)에서 평균 유효전력은 얼마인가?

💡 해설: L, C는 에너지를 저장·방출만 하므로 평균 유효전력은 0입니다.

Q2. 내부저항 R0인 전원에서 부하에 최대전력이 전달되는 조건은?

💡 해설: 부하저항이 내부저항과 같을 때(정합) 최대전력이 전달됩니다.

Q3. 기전력 E, 내부저항 R0일 때 최대전력 Pmax 공식은 E²/( )이다. 괄호 안은? (단답형)

💡 해설: 최대전력 Pmax = E²/4R0 입니다.

Q4. 복소전력 S=VI*에서 I*는 무엇을 의미하는가?

💡 해설: 복소전력은 전압과 전류 켤레복소수의 곱으로 정의됩니다.

5. 인덕턴스 및 벡터궤적

1. 자기 인덕턴스와 상호 인덕턴스

자기인덕턴스 L=Nφ/I [H] / 상호인덕턴스 M, 결합계수 k=M/√(L1L2) (0≤k≤1)

2. 인덕턴스의 접속(합성 인덕턴스)

가동(가극성) 결합: L=L1+L2+2M / 차동(감극성) 결합: L=L1+L2-2M

3. 이상 변압기

권수비 a = N1/N2 = V1/V2 = I2/I1

4. 벡터 궤적

주파수나 소자값을 변화시킬 때 임피던스(또는 어드미턴스) 벡터의 끝점이 그리는 자취. R-L 직렬회로에서 리액턴스를 변화시키면 반원 궤적을 그린다

✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

Q1. 결합계수 k = M/√( )에서 괄호 안은? (단답형)

💡 해설: 결합계수 k=M/√(L1L2) 입니다.

Q2. 가동(가극성) 결합일 때 합성 인덕턴스 L은?

💡 해설: 가동결합은 자속이 보강되어 L=L1+L2+2M 입니다.

Q3. 이상 변압기의 권수비 a = N1/N2 = V1/V2 = ?(전류에 대한 관계식) (단답형)

💡 해설: 권수비 a=N1/N2=V1/V2=I2/I1 입니다.

Q4. R-L 직렬회로에서 리액턴스를 0에서 무한대로 변화시킬 때 임피던스 벡터의 궤적은 어떤 모양인가?

💡 해설: R-L 직렬회로의 임피던스 벡터궤적은 반원을 그립니다.

중첩의 정리: 전압원 단락·전류원 개방 후 각각 해석해 합산 / 테브난의 정리: Vth와 Rth의 직렬 등가 / 노턴의 정리: IN과 RN의 병렬 등가 / 밀만의 정리: 여러 병렬 전압원의 등가전압 공식

💡 해설: 이상적 전압원은 내부저항이 0이라 부하와 관계없이 전압이 일정합니다.

Q2. 여러 전원이 있을 때 전압원은 단락, 전류원은 개방하여 각각 해석 후 합산하는 정리는?

💡 해설: 중첩의 정리에 대한 설명입니다.

Q3. 테브난 등가회로는 전압원과 무엇의 직렬 조합인가? (단답형)

💡 해설: 테브난 등가회로는 Vth와 Rth의 직렬 조합입니다.

Q4. 노턴 등가회로는 전류원과 저항의 어떤 조합인가?

💡 해설: 노턴 등가회로는 전류원과 저항의 병렬 조합입니다.

7. 대칭 n상 교류

1. 평형 3상 교류

Y결선: 선간전압=√3×상전압, 선전류=상전류 / Δ결선: 선간전압=상전압, 선전류=√3×상전류 / 3상 전력 P=√3 VL IL cosθ

2. 부하의 Y↔Δ 변환

ZΔ = 3ZY (Δ결선 임피던스는 Y결선의 3배)

3. 3상 전력의 측정(2전력계법)

단상 전력계 2대로 3상 전력을 측정: P = W1+W2, 역률 cosθ = P/(√3×√(W1²+W2²-W1W2))

✏️ 단원 확인문제 (3문제)
점수: 0 / 100점 (정답 0 / 3문제)

Q1. Y결선에서 선간전압과 상전압의 관계는?

💡 해설: Y결선은 선간전압이 상전압의 √3배입니다.

Q2. Δ결선을 Y결선으로 등가변환할 때 ZY = ZΔ/( )에서 괄호 안은? (단답형)

💡 해설: ZY=ZΔ/3, 즉 ZΔ=3ZY 입니다.

9. 비정현파 교류

1. 비정현파 교류

사인파가 아닌 주기적 파형(구형파, 삼각파 등)을 비정현파라 한다

2. 푸리에 급수

비정현파 = 직류분 + 기본파 + 각 고조파의 합으로 표현. 반파대칭이면 기수(홀수) 고조파만 존재

3. 비정현파의 계산

실효값 V = √(V0²+V1²+V2²+...) (직류분과 각 고조파 실효값의 제곱합의 제곱근)

4. 비정현파의 직렬 임피던스 및 결선

각 고조파(각속도 nω)마다 리액턴스가 다르므로(XLn=nωL, XCn=XC/n) 고조파별로 개별 계산 후 중첩하여 합산

✏️ 단원 확인문제 (4문제)
점수: 0 / 100점 (정답 0 / 4문제)

💡 해설: 비정현파는 푸리에 급수로 표현합니다.

Q2. 반파대칭인 파형에는 어떤 고조파가 존재하는가?

💡 해설: 반파대칭 파형에는 기수(홀수)차 고조파만 존재합니다.

💡 해설: n고조파의 유도 리액턴스 XLn=nωL 이므로 3고조파는 기본파의 3배입니다.

Z파라미터: 출력단자 개방 상태에서 정의 / Y파라미터: 출력단자 단락 상태에서 정의

6. 분포정수 회로

11. 라플라스 변환

F(s)를 부분분수로 분해한 뒤 각 항을 표준 변환쌍과 대응시켜 시간함수로 되돌린다

12. 과도현상

1. 과도현상

회로의 상태(스위치 On/Off 등)가 바뀐 직후, 새로운 정상상태에 도달하기까지의 일시적인 변화 과정

2. 직류 R-L 직렬회로

전류 i(t) = (E/R)(1-e^(-Rt/L)), 시정수 τ = L/R

3. 직류 R-C 직렬회로

전압 vc(t) = E(1-e^(-t/RC)), 시정수 τ = RC

4. 직류 R-L-C 직렬회로

감쇠 정도에 따라 과제동·임계제동·부족제동(진동)으로 구분되며, 이는 저항 R의 크기에 따라 달라진다

💡 해설: RL 직렬회로의 시정수는 τ=L/R 입니다.

Q2. RC 직렬회로의 시정수 τ = ?(R과 C로 표현) (단답형)

💡 해설: RC 직렬회로의 시정수는 τ=RC 입니다.

13. 전달함수

1. 전달함수

모든 초기값을 0으로 했을 때, 출력의 라플라스변환 / 입력의 라플라스변환 → G(s)=C(s)/R(s). 선형 시불변계에서만 정의
